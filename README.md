# АСД — Лабораторні роботи

Репозиторій з лабораторними роботами з дисципліни **«Алгоритми і структури даних»**.

**Виконав:** Щур Тимофій Вікторович  
**Група:** ІМ-65

## Структура репозиторію

| Папка | Зміст | Мова |
|---|---|---|
| `lab1` | Умовні оператори та логічні вирази (дві програми: поодинокі порівняння та булеві операції) | Go |
| `lab2` | Аналіз алгоритмів: вкладені цикли та динамічне програмування, побудова графіків | Go, Python |
| `lab3` | Алгоритми обходу двовимірних масивів | Go |
| `lab4` | Алгоритм двійкового(булевого) пошуку | Go |
| `lab5` | Алгоритм сортування, шейкерний метод | Go |
